---
name: brainstorm
description: >-
  Brainstorm possibilities when the user has an idea or open problem and wants
  to broaden the solution space before choosing a direction.
---

Build a possibility map for the user's later choice. Generate before
evaluating: optimize for spread across genuinely different dimensions,
including non-obvious branches, then group them with brief implications.
Ask only when missing context would materially change the map; finish when
the major branches are visible and ready for the user to choose where to go
deeper.
