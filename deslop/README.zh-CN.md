# Deslop / 说人话

Deslop 是一个支持中文、英文和中英混排的 Agent Skill。它编辑已有文本，清理
模板化的 AI Slop，同时保护事实、关系、语域和作者原有声音。

它是文字编辑器，不是 AI 检测器。它不提供 AI 概率，不承诺绕过检测器，也不会
为了“像人”而编造个性、经历或细节。

## 能做什么

- 把 AI 味明显的文本改成一个可直接使用的版本；
- 用户要求“先标问题”时只审稿，不改写；
- 保留事实、数字、归因、置信度和责任主体；
- 使用用户当次提供的样本或显式维护、范围匹配的作者偏好层校准文风；
  不保存样本，也不从当前文本自动学习或更新作者档案；
- 明确修改文件时保护 frontmatter、代码、数据和链接目标；
- 原文已经自然时保持不动。

## 安装

从合集安装：

```bash
npx skills add patrick-fu/awesome-skills -g -s deslop
```

## 使用

```text
用 $deslop 去掉这段文档的 AI 味，所有事实都不要变。

先用 $deslop 标出问题，不要直接改。

用 $deslop 修改这个 Markdown 文件，保留 frontmatter、代码块和链接目标。
```

单纯的“润色、翻译、总结、校对”不会触发 Deslop，除非用户同时明确要求去除
AI Slop、说人话或减少模板感。

## 设计

Deslop 使用统一的保真合同、按语言加载的模式库、场景化规则，以及三种内部
改动范围：`balanced`、`in-place`、`rebuild`。完整示例放在评测集，不占用正常
调用上下文。
