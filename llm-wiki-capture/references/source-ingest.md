# Source Ingest

Use this branch when external material is the object of an explicit ingest
request or an explicit review of whether and how it should enter the Wiki. A
URL supplied only as context for another task does not select this branch.

## Establish The Source Set

1. Use an available source-specific reader or API when it preserves the
   material better; otherwise use a generic browser or extraction path.
2. Resolve each supplied item's canonical identity, source type, author or
   publisher, publication date, and original URL when possible.
3. Compare canonical URLs, mirrors, reposts, translations, excerpts, and
   near-identical text against the Wiki before adding anything.
4. Prefer primary and authoritative evidence. Keep secondary interpretation
   when it contributes independent claims or retrieval value.
5. Convert audio, video, and image text into inspectable transcripts or OCR
   early. Preserve binary assets only when the asset itself is evidence.

## Traverse References By Value

Prioritize relevant, valuable first-hop references, but neither ingest every
first-hop link nor stop mechanically at depth one.

Apply qualitative depth decay:

- each deeper hop needs stronger relevance and evidence value
- ordinary background links lose priority quickly
- follow a second- or third-hop link only when it is unusually valuable or
  continues the material's central evidence chain
- keep the exploration budget bounded and record why deeper links were followed
  or skipped in the source summary or the repository's source-research notes

Avoid fixed scores and rigid depth caps. Stop when additional links no longer
change the claims, provenance, tensions, or canonical integration plan.

## Delegate For Independent Value

Prefer multiple agents when the host supports them and the source set benefits
from independent perspectives. Useful roles include source identity and
provenance, claim extraction, reference-chain research, existing-Wiki
deduplication, skeptical review, and final acceptance.

Give each agent an independent evidence set, question, or acceptance criterion.
Do not use a fixed agent count or delegate for appearance. The main agent must
verify conclusions against the source material and reconcile disagreements.

## Integrate

1. preserve raw evidence according to the repository schema
2. create or update source summaries only when they add retrieval value
3. weave stable claims into canonical concepts, comparisons, queries, and
   synthesis pages
4. represent tensions and uncertainty instead of averaging conflicting sources
5. update required indexes, logs, source roles, and backlinks

Source Ingest is complete when every accepted claim can be traced to its source
family under the provenance contract, the useful knowledge is discoverable
from its canonical owner, and the shared integration contract passes. In
review-only mode, report the proposed source set, reference traversal, raw
boundaries, owner pages, and skips without editing.
