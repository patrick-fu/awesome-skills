# 文件证据复盘

仅在用户明确要求复盘人生线索、创作路径或未来工作状态时使用。文件能证明发生过什么，
不能证明一个人的完整性格。

## 写法

1. 先划定证据范围：检查了哪些时期、目录和材料，缺失什么。
2. 按时间重建阶段与转折，只写材料支持的经历。
3. 提炼反复出现的主题、项目类型、角色、创作方式与工作节奏。
4. 区分：
   - **证据**：文件类别、日期、项目或文档主题；
   - **推断**：从多条证据归纳出的可能倾向；
   - **未知**：材料不足，不能判断。
5. 把未来方向写成小型、可逆的实验，并说明取舍。

## 建议结构

- 证据边界
- 时间线与转折
- 反复出现的主题
- 可能的能量来源与负担
- 工作状态偏好
- 下一步实验

使用“材料显示”“可能”“倾向”这类校准表达。每个推断至少关联一类可说明的文件证据，
但不披露敏感原文、身份信息或私人关系细节。

不做临床、人格类型或命运判断；不从缺失文件推断经历，不把整理习惯等同于人格，不替
用户决定职业或生活方向。
